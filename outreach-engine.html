Outreach Engine

An n8n cold-email sequencing workflow — built and tested locally, not deployed to a public server.

n8nCold EmailSequencing Logic
Workflow JSON built locally · not publicly deployed

The problem

Manual cold outreach caps out fast — copy-pasting the same email with small edits to 20 prospects a day is the ceiling for one person working by hand.

The solution

An n8n workflow takes a prospect list, sequences a multi-step cold-email send with spacing between touches, and logs status per contact — so outreach volume isn't capped by how fast someone can type.

Honest status: This workflow exists as a built JSON file, tested in a local n8n instance. It has not been deployed to a live server or run against a real prospect list at scale — described here as built, not shipped.
