Lazarus Engine

A 5-workflow n8n system that finds dormant CRM leads, scores them, and re-engages the ones worth chasing.

n8nOpenAI APIWhatsApp Cloud APISendGridGoogle Sheets
Live demo →

The problem

Every CRM has a graveyard of leads that went cold — no reply, no follow-up, quietly ignored because reaching back out to hundreds of dormant contacts by hand isn't worth anyone's time.

The solution

The system scans the lead database on a schedule, scores each dormant lead on viability, and sends an AI-personalized re-engagement message to the ones worth another shot — then watches for replies in real time.

Architecture

How the 5 workflows connect

Trigger
Cron schedule scans the lead database for contacts with no activity past a set threshold.
Score
Each dormant lead is scored for viability based on original enquiry data and time-since-contact.
Personalize
OpenAI API drafts a re-engagement message referencing the lead's original enquiry — not a generic "just checking in."
Send
Message goes out via WhatsApp Cloud API or SendGrid depending on available contact info.
Detect & handoff
Incoming replies are detected in real time and the lead is flagged "warm" in Google Sheets for immediate human follow-up.
Status: Self-built and tested end-to-end with sample/test data. No reactivation-rate figures are claimed — none have been measured against a real dataset yet.
