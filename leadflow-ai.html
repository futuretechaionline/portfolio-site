LeadFlow AI

A 7-workflow n8n suite that takes a real estate lead from form-fill to booked call — no manual handoff.

Live demo →

The problem

A lead fills a Facebook Ad form or Google Form for a property. In most agencies, that lead sits in a spreadsheet until someone manually reads it, decides how to respond, and follows up — often a day or more later, by which point the lead has already messaged three other agents.

The solution

The moment a form is submitted, a webhook fires. The lead's details are logged, an AI model reads the enquiry and drafts a personalized first message, and that message goes out over WhatsApp or email within seconds — while a Calendly link is offered for booking a call directly.

Architecture

How the 7 workflows connect

Trigger
Facebook Ads / Google Form submission hits an n8n webhook.
Capture
Lead data is normalized and written to a Google Sheets CRM row.
Personalize
The lead's enquiry is passed to the OpenAI API, which drafts a first-contact message matched to the property and enquiry type.
Deliver
The message sends via WhatsApp Cloud API if a phone number exists, otherwise SendGrid email.
Book
A Calendly link is included for the lead to self-book a call, no back-and-forth needed.
Track
Every send, reply, and booking event updates the same Sheets row, so the lead's status is visible without opening five different tools.
Notify
If a lead books or replies, an internal notification fires so a human takes over from there.
Status: Self-built and tested end-to-end with sample/test data. Not yet run against live client traffic — no production lead-volume claims are made here.
