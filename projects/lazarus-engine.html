Lazarus Engine

A 5-workflow n8n system that finds dormant CRM leads, scores them, and re-engages the ones worth chasing using AI.

⚠️ The Problem

Every CRM has a graveyard of leads that went cold — no reply, no follow-up, quietly ignored because reaching back out to hundreds of dormant contacts by hand simply isn't worth a human rep's time.

🎯 Example Persona

Real Estate Brokers & Sales Directors

Agencies with a backlog of 500+ aging leads sitting untouched in their database who want to unlock hidden revenue and reactivate interest without hiring more SDRs.

✅ The Solution

An automated engine that scans the database, scores dormant leads on viability, drafts highly contextual AI re-engagement messages, and watches for replies to instantly hand off to a human.

📸 n8n Execution Architecture (5-Part Workflow) system_02_n8n.png
Execution Architecture

How the 5 workflows connect

WORKFLOW 1: TRIGGER & SCAN
Cron Schedule executes daily, scanning the lead database for contacts with zero activity past a set time threshold (e.g., 90 days).
WORKFLOW 2: AI SCORING
Each dormant lead is parsed and scored for viability based on original enquiry data, property interest, and time-since-contact.
WORKFLOW 3: HYPER-PERSONALIZATION
OpenAI API drafts a custom re-engagement message directly referencing the lead's original enquiry (e.g., "Still looking in Yavatmal?") instead of sending a generic "just checking in" blast.
WORKFLOW 4: MULTI-CHANNEL SEND
Message routing logic dispatches the AI-crafted text via WhatsApp Cloud API or SendGrid depending on the available contact info.
WORKFLOW 5: DETECT & HANDOFF
Incoming replies are detected via Webhook in real time. The lead is immediately flagged as "Warm" and synced to Google Sheets/CRM for human follow-up.
