SYSTEM 06 · SELF-DIRECTED

HubSpot Lead Qualification, Routing & Sales SLA Automation

A self-directed HubSpot CRM project demonstrating MQL qualification, scoring logic, regional routing, sales follow-up, SLA checks, meeting tracking and CRM updates.

HubSpotLead ManagementMQL / SQLLead ScoringLead RoutingSales SLAWorkflow Automation
◆ Self-directed project · Practice implementation

⚠ The Problem

Leads can lose value when qualification rules are unclear, sales ownership is inconsistent, follow-up is manual, and there is no clear escalation path when a qualified lead is not contacted.

◉ Project Context

NovaScale AI · Simulated B2B AI/CRM consultancy

✓ The Solution

Designed a practical lead-management workflow that turns qualification requirements into HubSpot workflow logic: qualify the lead, route it by region, notify the appropriate sales path, create follow-up work, check the 24-hour SLA, then track meeting outcomes and exceptions.

Execution Architecture

Lead → Qualification → Routing → SLA → Meeting

The architecture translates business requirements into HubSpot conditions and actions while keeping qualification, routing, follow-up and exception paths explicit.

1

1 · MQL trigger

Enroll contacts when the agreed MQL condition is reached so the workflow begins from a clear qualification event.

2

2 · Qualification branch

Check company fit and high-intent signals such as company size, target industry, demo request or pricing inquiry.

3

3 · Qualification status

Update the practice CRM field to Qualified or Not Qualified so the qualification decision is visible and auditable.

4

4 · Regional routing

Route qualified leads by geography using defined branches, with a fallback path when no regional match exists.

5

5 · Sales handoff

Create the sales task and internal notification needed for follow-up, using a simulated routing field because the practice portal does not contain multiple real sales users.

6

6 · 24-hour SLA check

After the defined delay, check whether the sales follow-up requirement was completed.

7

7 · Meeting outcome

If sales activity is completed, check meeting status and update the CRM appropriately; otherwise use the escalation/exception path.

8

8 · Exit and exception handling

End completed paths cleanly and keep the exception path separate so a missed follow-up does not silently look like a successful handoff.
